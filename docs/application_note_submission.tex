\section{Introduction}
Engineering promoter sequences can tune gene expression and generate useful
quantitative trait variation in crops, as demonstrated by promoter editing
in tomato \citep{RodriguezLeal2017Engineering}. Studies of minimal and core
plant promoters have also identified sequence features that support the
design of promoters with different activities
\citep{Cai2020Minimal,Jores2021Synthetic}. For tissue-directed applications,
promoter selection must consider where expression occurs as well as its
strength: a candidate intended for fruit-focused expression should favor
fruit relative to vegetative tissues. Selecting candidates for this purpose
therefore requires an assessment of expression patterns across tissues.

Sequence-to-expression models have enabled prediction of plant transcript
abundance from regulatory DNA \citep{Washburn2019Evolutionarily}, while PhytoExpr extends this approach to computational searches for functional regulatory variants and species-specific regulatory sequences
\citep{Li2024PhytoExpr}. Complementary approaches introduce sequence
constraints or streamline the design process: DeepSEED conditions
flanking-sequence generation on predefined cis-regulatory elements
\citep{Zhang2023DeepSEED}, and GPro combines generation, prediction and
optimization within a common toolkit \citep{Wang2024GPro}. Beyond activity
tuning, deep-learning approaches have enabled cell-type- and tissue-directed
enhancer design in animal systems
\citep{Taskiran2024Enhancers,deAlmeida2024Enhancers,Gosai2024MachineGuided}.

However, the output used to guide candidate selection must match the
intended tissue preference. In PlantCRE, for example, the
sequence-to-expression predictor summarizes expression by its maximum
across tissues rather than returning a tissue-resolved profile
\citep{Qiu2025PlantCRE}. This type of summary cannot, by itself,
distinguish a fruit-biased candidate from one predicted to be active across
several organs. More generally, promoter design for tissue preference requires
scoring criteria that explicitly compare target and non-target tissues. For
tomato promoter design, this motivates linking motif-conditioned candidate construction to separate root-, stem-, leaf- and fruit-associated scores and an explicit target-versus-non-target
ranking criterion. This connection allows sequence constraints and
predicted tissue bias to be considered together when selecting candidates.

Here, we present TPSGen, a Python framework for motif-conditioned design
of tomato promoter candidates for tissue-biased expression. TPSGen uses
motif evidence to constrain sequence modifications, evaluates input and
designed sequences using four tissue-associated scores, and ranks
candidates according to target-tissue-associated scores while reporting a target-tissue bias measure. Candidate sequences,
motif annotations, tissue-associated scores and run provenance are
reported together to support reproducible selection of candidates for experimental evaluation.

\section{Implementation}

TPSGen is a modular Python command-line framework that standardizes tomato promoter design from input sequence to ranked candidates. 
The overall workflow consists of promoter interpretation, motif-guided candidate construction, tissue-associated scoring and candidate prioritization (Fig.~\ref{fig:framework}). 
The package separates sequence construction from candidate assessment, enabling generated candidates and input promoters to be evaluated using the same scoring and reporting scheme. A multi-record FASTA input is validated, interpreted, used for candidate construction and summarized in a common set of output files. The package-native route runs end-to-end without model retraining; input definitions and model settings are provided in Supplementary Sections S1--S4.

\subsection{Input representation and promoter processing}

The primary input is a multi-record FASTA file containing tomato promoter sequences represented as the project-defined 165-bp windows. In the source annotation, each window is defined relative to the annotated gene-start coordinate, which serves as a TSS proxy. TPSGen validates sequence length and alphabet, records rejected records and writes a provenance manifest containing the package version, route, seed and input summary.

Promoter interpretation is provided by a transparent package-native motif scanner and an optional DNABERT-based evidence route. The package-native scanner reports configured exact sequence-pattern matches, whereas the DNABERT route processes overlapping 6-mer tokens and reports position-associated evidence and model-derived recurrent sequence patterns \citep{Ji2021}. These evidence types are exposed separately through standardized tables that can be inspected before candidate construction (Supplementary Section S2).

\subsection{Candidate generation and tissue-associated scoring}

TPSGen separates candidate construction from prioritization while exposing both through the same workflow. The default route performs deterministic motif-aware editing by protecting detected motif positions from the selected motif evidence source and applying seeded substitutions to editable positions. When a compatible checkpoint is supplied, the optional preGAN route uses masked 165-bp templates and fruit-associated scalar guidance for conditional generation. Fruit-associated guidance is used during candidate generation, whereas four-tissue scoring is applied subsequently for tissue-bias prioritization. In both cases, generation denotes computational candidate construction and not experimentally confirmed promoter activity.

For prioritization, the selected scoring backend reports root-, stem-, leaf- and fruit-associated scores and calculates a target-bias margin as the target score minus the highest score among the three non-target tissues. In the model-backed route, TransVAE-MLP encodes each promoter sequence into a latent representation and maps it to the four tissue-associated scores. Candidates are ranked within each input sequence primarily by the requested target-tissue score, with target-bias margin used as a secondary criterion for tied scores. Scores from different backends are reported on their respective scales and are not compared across backends; these outputs are computational prioritization signals rather than TPM or experimentally validated tissue specificity (Supplementary Section S4).

A central function of TPSGen is to generate candidate FASTA records and evaluate them in the same schema as the input promoter. Each candidate is accompanied by its route, seed, protected-region summary, four tissue-associated scores, target-bias margin and quality-control fields. Sequence construction and candidate prioritization are therefore traceable within a common output schema.

Structured reports, example inputs, model resources and provenance manifests support reproducible use. The repository documents optional checkpoint-backed routes separately from the package-native workflow and records the selected backend for each run.

\section{Candidate Design and Scoring Validation}

We used the package-native workflow on 40 tomato promoter sequences of 165 bp, generating three candidates per input with a fixed seed and retaining the complete output manifest. Fruit was used as the target tissue in this demonstration because the available conditional generation route currently supports fruit-associated guidance.

The run produced motif annotations, candidate FASTA sequences, four score fields, quality-control summaries and a provenance report without manual format conversion. Candidates were ranked primarily using the requested target-tissue score, with fruit-bias margin used to resolve tied scores; these outputs support computational prioritization only and are not measurements of promoter expression.

The integrated output is illustrated in Fig.~\ref{fig:main-results}. In the package-native demonstration, the Rank-1 candidates show the distribution of fruit-associated scores and fruit-bias margins under the scoring procedure, together with their position-wise sequence composition (Fig.~\ref{fig:main-results}A,B,E). In the separate TransVAE-MLP validation analysis, Pearson correlations were 0.78, 0.82, 0.80 and 0.79 for root, stem, leaf and fruit, respectively (Fig.~\ref{fig:main-results}C); the fruit-associated target showed \(r=0.79\) and \(R^2=0.63\) across 3,703 validation records (Fig.~\ref{fig:main-results}D). These panels summarize the design outputs and scoring-model validation.

Model-specific validation results and their provenance are reported separately in the Supplementary Information and are not treated as an independent benchmark of the current package. Together, these results show that TPSGen links promoter characterization, candidate generation and tissue-bias prioritization through a reproducible output schema.

\section{Conclusion}

TPSGen provides a computational framework for motif-conditioned design of tomato promoter candidates with tissue-biased expression priorities. By connecting motif-aware sequence construction with tissue-resolved scoring, TPSGen supports candidate selection based on target-versus-non-target expression preference while retaining sequence information for downstream experimental evaluation.
