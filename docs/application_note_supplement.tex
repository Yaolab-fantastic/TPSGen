\section{Data and evaluation}

\subsection{Promoter sequences}

Promoter sequences were extracted from the SL3.0 tomato genome assembly using the ITAG3.2 GFF3 annotation distributed through Phytozome \cite{Goodstein2012,Sato2012}. The model-development dataset used the 165 nucleotides immediately upstream of positive-strand gene starts. Records containing unresolved bases or fewer than 165 nucleotides were excluded. Gene identifiers linked these windows to the expression data.

Annotated gene starts provide the coordinate reference for extraction and positional analyses and serve as proxies for transcription start sites (TSSs). All model inputs use a fixed length of 165 bp and the alphabet A/C/G/T. To prepare a negative-strand gene for inference, its upstream genomic sequence must be reverse-complemented into the promoter-to-gene orientation.

\subsection{Four-tissue expression targets}

Expression data came from the MicroTom metabolic network (MMN), which covers 20 organ--stage conditions \cite{Li2020}. We selected root, stem and leaf at 85 days post germination (R85, S85 and L85), and fruit at 15 days after breaker (Br15). Throughout the manuscript, root, stem, leaf and fruit denote these four measurements.

The promoter and expression tables were joined by gene identifier. Records without a valid promoter sequence or a matching expression record were excluded. The four expression columns were transformed using $\log(1+x)$, values below 0.01 were set to zero, and the remaining values were rounded to three decimal places. After excluding 2,966 genes with zero values in all four tissues, the ITAG-MMNP2E dataset contained 14,071 promoter--target records. Each record consists of a 165-bp sequence and four processed expression values.

For TransVAE-MLP development, the records were randomly split at the sequence level into 11,257 training, 1,407 validation and 1,407 test examples. The validation set was used for model selection, and the test set was used to assess prediction. Table~\ref{tab:data-resources} summarizes the resources used by the three model components.

\subsection{DNABERT and preGAN datasets}

DNABERT pretraining used 34,725 500-bp sequences upstream of ITAG3.2 gene starts, partitioned 80:20 for training and validation. Fine-tuning used 4,448 165-bp examples, with equal numbers of promoters and randomly sampled non-promoter genomic segments. These examples were split 70:15:15 into training, validation and test sets. The 500-bp context was used for pretraining, while the downstream promoter classifier and design workflow use 165-bp sequences.

preGAN used 5,100 promoters selected for high Br15-associated expression. For each reference sequence, high-evidence regions identified with DNABERT were retained and editable positions were replaced by \texttt{M}. The masked template is denoted \texttt{realA} and the complete reference \texttt{realB}. Generator training used the first 80\% of the paired records (4,080); the remaining 1,020 records were outside this training subset. A separately pretrained DenseNet--LSTM predictor supplied the scalar fruit-expression constraint.

\subsection{Evaluation metrics}

Expression prediction and $k$-mer-frequency agreement were assessed using the Pearson correlation coefficient (PCC). Promoter classification was assessed using accuracy, F1 and the Matthews correlation coefficient (MCC). Additional analyses used masked-token perplexity, retained-position agreement, pairwise edit distance and BLAST E-values. Model-derived motif evidence denotes recurrent sequence patterns associated with the trained classifier. Predicted expression scores are used to prioritize candidate promoters for experimental evaluation.

For candidate selection, the four raw checkpoint outputs are transformed with the softplus function. Let $s_i(x)$ denote the resulting nonnegative score for tissue $i$ and $s_{\max}(x)=\max_i s_i(x)$. For $s_{\max}(x)>0$, profile concentration is summarized by
\[
\tau(x)=\frac{1}{n-1}\sum_{i=1}^{n}
\left(1-\frac{s_i(x)}{s_{\max}(x)}\right),\qquad n=4.
\]
Values near one indicate concentration in one tissue, while values near zero indicate an even profile. The favored tissue is identified by the largest score. The default threshold of 0.7 is an operational threshold used in this study rather than a universal biological boundary. Profiles without a positive maximum are ineligible for selection. Target-specific selection also uses the margin defined in Section S4.3.

\section{Sequence evidence and conditioning regions}

\subsection{DNABERT pretraining and classification}

DNABERT followed the sequence-language-model formulation of Ji et al.\ \cite{Ji2021}. Sequences were converted to overlapping 6-mers with a one-nucleotide stride. During pretraining, 15\% of token positions were selected for corruption, and the model learned to recover the original tokens from their context. The configuration used 200,000 training steps, a learning rate of $4\times10^{-4}$, weight decay of 0.01, 12 Transformer layers and 12 attention heads. The selected model reached a perplexity of 3.98.

The pretrained encoder was fine-tuned for promoter/non-promoter classification using the 165-bp dataset described in Section S1.3. On its held-out test set, accuracy was 0.905, F1 was 0.906 and MCC was 0.813. These results characterize the classifier used to derive the positional evidence.

\subsection{Position-wise evidence}

Token-level attention evidence from the fine-tuned classifier was mapped to nucleotide coordinates. Because adjacent 6-mers overlap, each position aggregates evidence from the tokens that cover it. Promoter and random-gene sequences were processed using the same mapping convention.

The promoter profile showed a concentrated signal approximately 50--30 bp upstream of the annotated gene-start proxy, whereas the random-gene profile was more diffuse (Fig.~\ref{fig:supp-dnabert}B). This positional evidence was used to nominate regions for retention during candidate generation.

\subsection{Recurrent patterns and mutagenesis}

High-evidence segments were consolidated into recurrent sequence patterns. The summary included CTATT, ACTAA, ATCCA and TTTAT with 239, 188, 184 and 121 retained instances, respectively. Sequence logos show the aligned local windows, with nucleotide counts on the vertical axis (Fig.~\ref{fig:supp-dnabert}C).

In-silico mutagenesis perturbed bases in selected regions and measured the change in masked-language-model loss relative to the original sequence. Increased loss indicates that the model assigns greater support to the original local context. This analysis complements the positional evidence used to construct the conditioning templates (Fig.~\ref{fig:supp-dnabert}D).

\subsection{Template construction}

The DNABERT route accepts 165-bp promoter sequences and returns promoter and positional evidence. Selected high-evidence regions define the retained positions in a conditional template, and the remaining positions are marked editable. The package also provides an exact-pattern scanner for configured motifs. The selected annotation backend is recorded with the template so that its conditioning regions can be traced to their evidence source.

\section{Motif-conditioned generation}

\subsection{Template and sequence representations}

preGAN performs conditional completion of the 165-bp templates described in Section S1.3. Each training pair contains a masked template, \texttt{realA}, and its complete reference sequence, \texttt{realB}. Known bases have four-channel encodings. Masked positions are initialized with random vectors of length four.

Let $a$ denote this encoded template. The generator $G$ produces a probability matrix $P=G(a)\in[0,1]^{L\times4}$, where $L=165$. Let $\hat{x}$ denote the discrete candidate obtained by decoding these per-position nucleotide probabilities. Template conditioning determines the sequence context supplied during generation, and retained-position agreement is assessed on the decoded candidates.

\subsection{Generator, critic and expression guidance}

preGAN combines a conditional Wasserstein generative adversarial network with gradient penalty (WGAN-GP) and a frozen DenseNet--LSTM expression predictor. The generator maps the flattened template through a 512-channel linear projection, three one-dimensional convolutional residual blocks and a four-channel softmax output. The critic uses an initial one-dimensional projection and three residual blocks. It receives the template concatenated across channels with either the encoded reference or the generated output.

The generator objective is
\[
\mathcal{L}_{G}=\mathcal{L}_{\mathrm{adv}}
+\lambda_{L1}\mathcal{L}_{L1}
+\lambda_{\mathrm{fruit}}\mathcal{L}_{\mathrm{fruit}},
\]
where $\mathcal{L}_{\mathrm{adv}}$ is the adversarial loss, $\mathcal{L}_{L1}$ is the condition-consistency loss, and $\mathcal{L}_{\mathrm{fruit}}$ is the fruit-expression prediction loss. The coefficients $\lambda_{L1}$ and $\lambda_{\mathrm{fruit}}$ weight the two auxiliary terms. The $L_1$ term compares the generated four-channel output with the complete encoded template, including the random vectors at masked positions. The fruit term is the squared difference between the frozen predictor's scalar output and the specified target value.

The DenseNet--LSTM predictor combines convolutional, recurrent and densely connected features with a scalar regression output. It was trained with mean-squared error before integration into preGAN and had a reported PCC of 0.72 in its model comparison. Its frozen output supplies the fruit-expression term during generator training. After candidate generation, TransVAE-MLP supplies the four-tissue comparison used for selection.

Generator and critic learning rates were $10^{-4}$, the gradient-penalty coefficient was 10, and the batch size was 32. Training ran for 10,000 iterations, with five critic updates per generator update. Intermediate model and sequence outputs were recorded every 100 iterations.

\subsection{Condition retention and sequence distributions}

Conditional fidelity was measured on the retained positions. Let $x$ be the reference nucleotide sequence, $\hat{x}$ the decoded candidate, and $\Omega_R=\{i:\texttt{realA}_i\ne\texttt{M}\}$ the set of retained positions. The retention rate was
\[
R_{\mathrm{retain}}=\frac{100}{|\Omega_R|}
\sum_{i\in\Omega_R}\mathbb{I}(\hat{x}_i=x_i),
\]
where $\mathbb{I}$ is the indicator function. The reported retention rate was 99.55\%.

Sequence-distribution learning was monitored using generated and reference 4-mer frequencies at iterations 99, 4,999 and 9,999. The regional evaluation considered the full 165-bp sequence, the first 20 bp and the last 20 bp in the stored orientation. Generated-versus-reference PCC values were 0.98, 0.77 and 0.86, respectively (Fig.~\ref{fig:supp-pregan}A).

In a separate model comparison, preGAN yielded 4-, 5- and 6-mer PCC values of 0.95, 0.93 and 0.89. Corresponding values were 0.92, 0.90 and 0.88 for TransVAE-MLP-generated sequences and 0.91, 0.88 and 0.86 for WGAN (Fig.~\ref{fig:supp-pregan-comparison}A). These comparisons assess agreement with the reference promoter sequence distributions at three word lengths.

\subsection{Candidate diversity and tissue profiles}

We compared pairwise edit distances for generated, natural and random sequences (Fig.~\ref{fig:supp-pregan}B). BLAST searches against the tomato sequence database assessed similarity to reference sequences (Fig.~\ref{fig:supp-pregan-comparison}B). The generated distributions fell between those of the natural and random controls.

We sampled 20 preGAN candidates and used TransVAE-MLP to score them for R85, S85, L85 and Br15. The displayed profiles generally favored Br15 (Fig.~\ref{fig:supp-pregan}C,D). The four-score profile allows the fruit score to be assessed against the three non-target scores, while $\tau$ summarizes profile concentration. Target-specific selection uses the scores and thresholds described in Section S4.3.

\subsection{Candidate generation in TPSGen}

The preGAN interface accepts masked templates and a compatible generator checkpoint and returns the requested number of candidate sequences. The workflow checks sequence quality and agreement at retained positions. Candidates can be passed to the selected scoring backend, with the generator, scorer and checkpoint paths recorded in the run metadata. The package-native generation option is described in Section S5.1.

\section{Four-tissue prediction and candidate selection}

\subsection{TransVAE-MLP}

TransVAE-MLP learns sequence reconstruction and expression regression from the ITAG-MMNP2E records. A 165-bp sequence is encoded as nucleotide tokens with positional information. A Transformer encoder and convolutional bottleneck parameterize a latent distribution with mean $\mu$ and variance $\sigma^2$. During training, a latent representation $z$ is sampled by reparameterization. A Transformer decoder reconstructs the sequence, and an MLP predicts the four processed expression targets in the order R85, S85, L85 and Br15.

The training objective is
\[
\mathcal{L}_{\mathrm{total}}=\mathcal{L}_{\mathrm{recon}}
+\beta\mathcal{L}_{\mathrm{KL}}
+\lambda_{\mathrm{expr}}\mathcal{L}_{\mathrm{expr}}
+\lambda_{\mathrm{3mer}}\mathcal{L}_{\mathrm{3mer}}.
\]
The terms are sequence reconstruction, Kullback--Leibler regularization, four-target regression and 3-mer composition loss, respectively. The coefficients $\beta$, $\lambda_{\mathrm{expr}}$ and $\lambda_{\mathrm{3mer}}$ control their relative contributions. Training used a ten-epoch KL warm-up, three encoder layers, three decoder layers, four attention heads, batch size 128, 300 epochs, learning rate 0.0002 and weight decay 0.05. At scoring time, the MLP takes the deterministic latent mean $\mu$ to produce the four-score profile.

\subsection{Prediction evaluation}

On the 1,407-record model-development test set, PCC values were 0.77, 0.82, 0.79 and 0.78 for R85, S85, L85 and Br15. PCC measures the linear association between predictions and the processed expression labels. A separate architecture comparison on the ITAG-MMNP2E dataset reported Transformer-regression PCC values of 0.81, 0.85, 0.78 and 0.82 (Table~\ref{tab:transvae-results}).

Main-text Figure~2C,D characterizes the scoring checkpoint on a 3,703-record held-out validation cohort used for checkpoint characterization. Correlations were 0.78, 0.82, 0.80 and 0.79 across the four targets. These results are not presented as an independent external evaluation. Table~\ref{tab:transvae-results} distinguishes this cohort from the 1,407-record model-development test set.


\subsection{Candidate profiles and selection}

For a requested tissue $t$ and candidate $x$, the target score is $s_t(x)$ and the target-bias margin is
\[
\Delta_t(x)=s_t(x)-\max_{j\ne t}s_j(x).
\]
The maximum is taken over the three non-target tissues. A positive margin means that the target score exceeds every non-target score. Candidates labelled \texttt{paper\_strict} must pass sequence-quality and retained-position checks, have the requested tissue as the highest-scoring tissue, satisfy the minimum target-bias margin, and meet the requested concentration threshold ($\tau\geq0.7$ by default). Eligible candidates are ranked within each input first by target-bias margin and then by target score.

When strict preGAN selection is empty, the workflow can first search positions marked editable in the template and reapply the strict criteria. If strict selection remains empty, the optional adaptive mode can return candidates that retain the requested tissue as the highest-scoring tissue and satisfy the minimum margin at a lower effective $\tau$ threshold. Its candidates are labelled \texttt{adaptive\_target\_biased}, and both the requested and effective thresholds are recorded.

A separate TransVAE-MLP generation analysis used a genetic algorithm to search the learned latent space and decoded selected representations. Twenty generated candidates were sampled for presentation and scored across the four targets (Fig.~\ref{fig:supp-transvae}C,D). Many of the displayed candidates have higher Br15-associated scores than their other three scores. This analysis characterizes TransVAE-MLP's latent-space generation route. The preGAN candidate analysis is presented in Section S3.4.

\subsection{Checkpoint inference and constrained search}

TPSGen uses the historical-compatible checkpoint for four-tissue scoring. Token slicing and attention masks follow the training convention. Input and generated sequences are evaluated by the same checkpoint, and each output records the four scores, preferred tissue and checkpoint identity.

When strict preGAN selection yields no candidates, the workflow can perform a bounded search over positions marked editable in the conditional template. Each resulting sequence is scored with the selected checkpoint, with checks on sequence quality, retained positions, preferred tissue, target margin and the requested threshold. This sequence-level search uses the scorer to guide candidate selection. The latent-space generation analysis in Section S4.3 describes a separate experiment.

\section{Software workflow and outputs}

\subsection{Execution routes}

The model-backed workflow uses DNABERT evidence to define conditioning regions, preGAN to generate candidates with fruit-expression guidance, and TransVAE-MLP to compare scores across the four tissues. The generation and scoring backends are selected separately. Table~\ref{tab:execution-routes} summarizes the model components and package-native alternatives.

The package-native route is the default demonstration and can run without neural checkpoints. It keeps selected motif positions unchanged during sequence substitution. The model-backed route combines DNABERT and preGAN with the TransVAE-MLP scorer (Section S4.4). For DNABERT, \texttt{predict-dnabert} performs inference and \texttt{annotate-dnabert} processes precomputed attention resources.

\subsection{Inputs and outputs}

The input is a multi-record FASTA file with unique sequence identifiers. The model-backed routes require 165-bp sequences containing A/C/G/T, and the input validator checks lengths and characters before execution. The bundled example provides an input fixture for the software demonstration.

Each run writes the validated input FASTA, motif annotations, candidate FASTA sequences, candidate metadata, separate and combined input/candidate score tables, a workflow summary, a JSON report, diagnostic figures and a provenance manifest. Candidate records link each design to its source promoter, rank, target tissue, sequence differences, retained regions and quality-control status. Score tables include the four tissue-associated scores, preferred tissue and target margin. The manifest records input and candidate counts, output paths, the generation and scoring backends, checkpoint paths, random seed and requested and effective thresholds.

\subsection{Example commands}

The package-native demonstration is run with:
\begin{verbatim}
tpsgen run \
  --input examples/demo_input.fasta \
  --target fruit --candidates 3 --seed 42 \
  --output outputs/demo_run
\end{verbatim}

\noindent\begin{minipage}{\linewidth}
To use TransVAE-MLP scoring in this workflow, select the scoring backend:
\begin{verbatim}
tpsgen run \
  --input examples/demo_input.fasta \
  --target fruit --candidates 3 --seed 42 \
  --scoring-backend transvae \
  --output outputs/demo_transvae_run
\end{verbatim}
\end{minipage}

The scoring-backend option selects the predictor; candidate generation is configured separately. The seed controls package-native sequence substitutions and is recorded with the run.

\subsection{The 40-promoter demonstration}

The main-text software example used fruit as the target and generated three candidates for each of 40 inputs, yielding 120 sequences. Input promoters and candidates were evaluated with the same package-native scorer, not the TransVAE-MLP checkpoint evaluated in Figure~2C,D. The top-ranked candidate for each input was used in Figure~2A,B,E. These are pre-selection demonstration outputs and are not restricted to candidates passing the strict tissue-bias criteria; Figure~2B can therefore include negative margins. This demonstration presents the software outputs alongside the model-component evaluations in Sections S2--S4.
